# Movie Info App

## Problem
There is no single place that shows a personally curated "10 best movies" list broken down by year, with enough detail (cast, streaming links, personal notes) to decide what to watch next.

## Target user
The founder, initially, browsing their own curated picks. The app is public, so anyone can browse the same lists.

## Value in one line
See the 10 best movies for any given year, hand-picked, with the details needed to actually watch them.

## v1 scope
- Browse by year, each year shows a top-10 list
- Each movie has a detail page: poster, synopsis, rating, cast, a personal note on why it made the list, and streaming links
- Founder can add and edit movies and yearly lists (self-editing, login-gated)
- Public users can search and filter movies
- User accounts, so a visitor can save favorites or a watchlist

## Non-goals for v1
- No social features (comments, sharing, following other users)
- No recommendation algorithm, personalization is not in scope, the founder curates every list by hand
- No mobile app, web only

## Success criteria
- The founder can log in, add a year, and populate its top-10 list without help
- A visitor can browse any year's list, open a movie's detail page, and find a working streaming link
- A visitor can create an account and save a movie to their watchlist
