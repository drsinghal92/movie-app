## Story
As a visitor, I want to open a movie from a yearly list and see its full detail, so that I can decide whether and where to watch it.

## Origin
PRD story block, `**Added.**` marker. /ideate.

## Acceptance criteria
- [x] **AC1.** When a visitor opens a movie from a yearly list, the system shows its poster, synopsis, rating, and cast.
- [x] **AC2.** The detail page shows the founder's personal note on why the movie made that year's list.
- [x] **AC3.** The detail page shows one or more streaming links for the movie.
- [x] **AC4.** When a streaming link is unavailable for a movie, the system shows that no streaming link is available instead of a broken link.

## Out of scope
User reviews or ratings, saving the movie to a watchlist.

## Context
PRD: E01 / S-002. DESIGN: Movie detail (linked + no-link states). ARCHITECTURE: Next.js App Router + Prisma, `code/frontend`.

## Tasks

Goal-backward: at the end, a visitor clicks a poster on a published year's
list and lands on a detail page showing the movie's poster, synopsis, rating,
and cast (AC1), the founder's personal note (AC2), and a row of streaming-link
buttons (AC3); when the movie has zero streaming links, that row is replaced
by a plain "No streaming link available yet" line in the errnote visual
language, never a dead link (AC4). The schema already carries every field this
needs (`Movie.personalNote`, `StreamingLink` relation, per S-001), so no
migration: this is one canonical read, one route, one page, and its tests.
Add-to-watchlist and the not-logged-in prompt (DESIGN 3.3) belong to S-007 and
are out of scope here. Detail route is keyed by the movie cuid at
`/movies/[id]`; the canonical read guards on the parent year's `published`
flag exactly as `getYearWithMovies` does, so an unpublished movie's detail page
is unreachable even by a guessed URL, and returns the year number for the
back-to-year breadcrumb.

- [x] **T1** `[backend]` Add `getMovieDetail(id)` returning poster, synopsis, rating, cast, personalNote, streamingLinks, and year, null for absent/unpublished -> `code/frontend/src/lib/movies.ts` -> satisfies AC1, AC2, AC3, AC4
- [x] **T2** `[frontend]` Give PosterCard an href to `/movies/[id]` and pass each movie's id from the year page -> `code/frontend/src/components/poster-card.tsx`, `code/frontend/src/app/years/[year]/page.tsx` -> satisfies AC1
- [x] **T3** `[frontend]` Build the movie detail page per DESIGN 3.3: breadcrumb, poster, title, rating pill, cast, synopsis, note card, streaming-link row with the no-links errnote fallback, notFound/errnote states -> `code/frontend/src/app/movies/[id]/page.tsx` -> satisfies AC1, AC2, AC3, AC4
- [x] **T4** `[test]` Unit-test `getMovieDetail` for fields returned, note present, links present, links empty, and null on unpublished/absent -> `code/frontend/tests/unit/movies.test.ts` -> proves S-002-AC1, S-002-AC2, S-002-AC3, S-002-AC4
- [x] **T5** `[test]` E2E test that clicks a poster from a year list into the detail page and asserts poster/synopsis/rating/cast, the note, a streaming-link button, and the no-link message on a linkless movie -> `code/frontend/tests/e2e/movie-detail.spec.ts` -> proves S-002-AC1, S-002-AC2, S-002-AC3, S-002-AC4
